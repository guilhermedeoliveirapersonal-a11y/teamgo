# TEAM GO!

Páginas do app TEAM GO! e do painel do treinador (ícone, nome e tela cheia no celular).
Elas montam as telas com o código que vem do Google na hora e conversam com o Google pela porta de dados.
Aqui não há código das telas do app nem dados de alunos.

- `app/` — app do aluno (`?a=código`)
- `painel/` — painel do treinador (a chave vai depois do `#`)
- `ponte.js` — conversa com o Google sem usar as contas conectadas no celular
